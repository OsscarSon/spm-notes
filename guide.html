先做这三步

只想先看内置笔记，可以跳过第 2、3 步。

  1. 把它装成 App

    点右上角的 📲，按提示操作：安卓点浏览器右上角 ⋮ → 安装应用；iPhone 用 Safari，点底部分享按钮 → 添加到主屏幕 → 添加；电脑用 Chrome 或 Edge，点地址栏最右边的安装图标。装好后桌面会有「SPM备考」图标。

    从聊天软件点开链接时，常常落在 App 内置的小浏览器里。那里不能安装 App，填好的 key 也可能下次就不见了，请先改用 Safari 或 Chrome 打开。

  2. 申请免费的 Gemini key

    打开 aistudio.google.com/apikey，登录后点「Create API key」，复制那一长串字符。

    • 请用自己的 Gmail，不要用学校账号：学校账号可能被管理员限制或停用，key 也会跟着失效。
    • 打不开时先检查账号年龄是否已超过 18 岁；用手机时别在 Google 的应用里登录，改用 Chrome。
    key 只保存在你的浏览器里。不要发给别人，也不要截图。

  3. 贴进设置，再选科目

    点右上角「设置」，把 key 贴进「Gemini API key」那一栏，点「保存」，模型不用改。接着在「我考的科目 & 信心」勾选你考的科目，给每一科打 1 到 5 分：1 是没把握，5 是很稳。越没把握，越常排进今天的重点。笔试开始日默认是 2026-11-23，不一样再改。

今日

打开 App 先到这里。顶部那一排圈像 OMR 答题卡：每过一天涂掉一个圈，红色是今天，蓝色粗边是笔试第一天。

  • 今天的重点每天排 2 科，按你设的信心自动挑。必须及格的科目（如历史）和快要考的科目会排得更多，每科都附「下一章」的链接。
  • 今日清单自己加事项，打勾或删除。
  • 各科进度在笔记里给章节勾「已复习」，进度条就会前进。
  • 各科考试日期已按官方 JWP 时间表设好，也可以手动改；往下还有考试时间线、目标成绩点数估算和考试日清单。
成绩点数只是估算，真实成绩以 LP 公布为准。

笔记

先在顶部选科目，再点一章展开。每章都有内置要点，不用 key 就能看。

  • 章节要求：在每章的输入框里写老师划的范围，例如「1.2 只考定义和公式」。AI 生成笔记、出题、回答时都会参考它。
  • ✨ AI 生成这一章的笔记：生成后会标明由哪个模型完成。不满意可以重新生成，旧版本会收进「历史版本」，随时恢复。
  • 批量生成本科笔记：一次生成整科，很耗额度，建议先配好备用 AI（见「额度与备用 AI」）。
  • 高亮：在 AI 笔记里选中文字，点出现的「🖍 高亮」；选中已高亮的字可以擦除。
  • 搜索：顶部搜索框会搜遍所有科目的笔记，拼写差一点也能找到。

闪卡

点卡片或「显示答案」翻面，再选「记得」或「不记得」。同一张卡连续答对 3 次算掌握，不记得的会进错题本。也可以让 AI 按章节生成 6、10 或 15 张，或自己添加。

刷题

顶部的小标签切换玩法。题源可以选 AI 按章节出题（难度有基础、SPM 中等、KBAT 偏难），或用内置题库（仅选择题，附华文翻译）。

  • 选择题 / 作答题 / 混合：作答题一题一题做，写完点「提交批改」，AI 马上给分和评语。
  • 阅卷官：自己贴上题目、评分要点和你的答案（也可以拍照），AI 按得分点逐点给分。
  • 听力（国语、英文）：AI 写好对话或广播稿，用手机语音朗读。设备没有对应语音时只能看原文。
  • 作文（国语、英文、华文）：AI 按内容、语言、结构、词汇四项评分（华文最后一项是书写规范）。
  • 错题本：答错或失分的题自动进来，可以点「AI 讲解」弄懂为什么错。
AI 出的题可能有错，可疑的请对照课本。

模拟卷

AI 按 KSSM 和 SPM 的风格出整份卷，你在页面里作答，交卷后按评分要点批改并写评语。这是仿真练习，不是某一年的真题。

  • 选卷别后，题数、难度和限时默认「跟历届一样」，也可以自定义，还能只选几章。
  • 作答中有倒计时；中途关掉页面，草稿会自动保存。
  • 想更像 Trial，先到「资料」页上传一份 Trial 卷并勾选，AI 会模仿题型、设问方式和分值分布，但不会照抄原题。
  • 做完的成绩会记在「成绩记录」，也可以手动补记外部真题的成绩。

问答

把不懂的题打进去，或点「📷 上传题目图片」拍照问。范围可以选整科，也可以锁定某一章；勾上「只依据我的资料回答」后，资料里没有的内容会标成 [通用知识]，不会冒充课本原文。每个回答下面会写明参考了哪些章节、由哪个模型回答。

资料

上传 PDF、图片或文本，勾选后，问答、出题和出卷都会参考它们。下面还有 LP 官方、各科真题和 Trial 卷的入口。

超过 14 MB 的大文件会先上传到 Google，需要有 Gemini key。备用 AI 读不了你上传的文件和图片。

好用的小功能

PPT 模式

章节旁点「📊 PPT」，用幻灯片复习内置要点，方向键或按钮翻页，Esc 关闭。

互动实验室

笔记页底部有周期表、函数图像、几何画板、分子结构、思维导图、拍照识字等，点开才下载。

读书音乐

右上角 🎧：雨声、海浪、咖啡馆等，还有番茄钟。声音全是现场合成的。

在线名单

右上角 👥，看现在谁在读书。别人只能看到昵称、头像、科目和专注状态，可随时取消「让别人看到我」。需要联网。

专注房间

在 👥 面板里切到「专注房间」，选一个场景，比如樱花书院、温泉小筑、红砖咖啡楼、森林木屋，设个目标，点「进入」开始第一轮。

成就

复习章节、刷题、连续学习都会解锁成就，点小奖杯查看。

小宠物

住在页面角落，可以摸、可以拖动；在设置里换种类或关掉。

外观与壁纸

设置里有 10 种主题，壁纸可选小狗、Minecraft 或自己的图片。

笔记也能「🖨 打印 / 存 PDF」：在打印窗口的目的地选「另存为 PDF」。

额度与备用 AI

免费 key 的额度有限，用完会提示「太频繁」。等一两分钟或隔天再试，也可以多申请两个免费 key 当后备：Groq 和 OpenRouter，填在设置的「备用 AI」。

  • 默认开着「自动选择最合适的 AI」：每次生成前，按任务类型、各家今天的额度和有没有被限流来挑，不是等 Gemini 用完才换。
  • 要读你上传的 PDF 或图片时，一定用 Gemini。
  • 免费模型的名字常常改。提示「找不到模型」时，到该服务的网站查最新名字，再填进模型栏。

备份与同步

你的进度、AI 笔记和错题只在这个浏览器里。换设备或清缓存前，到设置最下面的「备份」点「导出 JSON」（文件不含 key，也不含上传的资料），到新设备再「导入 JSON」。

想让手机和电脑自动保持一致，可以开「云端同步」：用你自己免费的 Cloudflare 账号建一个 KV 和一个 Worker，把网址填进设置。设置页里有逐步图文说明，不用绑信用卡。

同步靠 API key 认人：每台设备必须填完全一样的 key，多一个空格都不行。换了 key 就等于换了一个新的同步空间。

常见问题

AI 的按钮是灰色的

还没有填 key。页面上方会出现黄色的「先设置 API key」提示，到设置页填好并保存就行。

提示太频繁，或今天额度用完了

等一两分钟，或隔天再试。经常遇到的话，配上 Groq 和 OpenRouter 的备用 key。

打不开 AI Studio，申请不了 key

先确认 Google 账号的年龄已超过 18 岁；用手机时别在 Google 的应用里登录，改用 Chrome。不要用学校账号。

换了手机，资料不见了

资料存在浏览器里，换设备不会自动带过去。换之前先导出备份，或开云端同步。

有新内容，但页面没变化

看右上角 🔔 的更新记录；底部出现「有新版本了」时点「刷新」。

笔记和答案可靠吗

它们由 AI 整理，仅供复习。遇到可疑的地方，请对照课本和老师的讲解。
